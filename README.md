\# 🚀 Job Portal



A full-stack Job Portal web application where candidates can search and apply for jobs, employers can create and manage job postings, and administrators can manage users, jobs, and applications.



\## ✨ Features



\### 👤 Candidate

\- Register and login

\- Manage candidate profile

\- Search and view jobs

\- Apply for jobs

\- Withdraw applications

\- Save and remove jobs

\- Track application status

\- View notifications



\### 🏢 Employer

\- Register and login

\- Manage company profile

\- Create job postings

\- View and edit jobs

\- Close job postings

\- View applicants

\- Update application status



\### 👨‍💻 Admin

\- Admin dashboard

\- View and manage users

\- Activate/deactivate users

\- Change user roles

\- Delete users

\- Manage jobs

\- Manage applications

\- Update application status
